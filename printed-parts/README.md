# Printed parts (coming)

ArmDojo's own printed parts for the HD-1910 duck will be published here as print-oriented STL and STEP files, with the print settings we used. They are designed around the HD-1910's measured dimensions.

Until then, print the parts from the HD-1910 release of the build you follow, and print one bearing seat and one servo mount first to check the fit. Our guide to [cleaning up 3D-printed robot parts](https://armdojo.com/blogs/guides/clean-up-3d-printed-robot-parts-supports-bearing-seats?utm_source=github&utm_medium=referral&utm_campaign=armdojo-duck) covers bearing seats and servo pockets, and the [bearing and screw pack](https://armdojo.com/products/microduck-bearing-screw-pack-hd-1910-duck?variant=51277756399855&utm_source=github&utm_medium=referral&utm_campaign=armdojo-duck) has the bearings both builds use.

The files will be licensed CC BY-NC-SA 4.0, like the rest of this repository.
